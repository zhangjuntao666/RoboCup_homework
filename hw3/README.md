# 第二次视觉作业：Sobel、Canny、Harris 与直方图均衡化

本作业通过 Jupyter Notebook 实现图像梯度计算、边缘检测、角点检测和灰度直方图均衡化，并展示各阶段的处理结果。

核心计算过程使用 Python 和 NumPy 手动实现。OpenCV 用于读取灰度图和生成一维高斯核，Matplotlib 用于绘图；未直接调用 `cv2.Canny`、`cv2.cornerHarris` 或 `cv2.equalizeHist` 完成主要任务。

## 2. 运行方法

使用 Python 3，主要依赖 NumPy、OpenCV、Matplotlib，以及用于运行 Notebook 的 Jupyter。

在已配置的 Python 环境中，进入本仓库的 `hw2/` 目录，按需安装依赖：

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyter lab
```

打开 `cv2.ipynb`，选择已安装上述依赖的 Python 内核，重启内核并从上到下运行全部单元格。

- Notebook 使用 `Path.cwd()` 定位项目目录，因此运行时的工作目录应为 `hw2/`。
- 输入文件应为 `image/input.jpeg`。如果更换文件名，需要同时修改准备阶段和直方图均衡化阶段的读取语句。
- `result/` 目录会自动创建；重新运行会覆盖同名结果图。
- 滤波使用逐像素循环，Harris 实验需要多次滤波，大图运行时间会较长。本次保存结果的输入图像为 400 × 400。
- 当前代码含有 `dtype=np.bool`。为兼容不同 NumPy 版本，可以将这两处统一改为 `dtype=bool`。

## 3. 算法实现

### 3.1 高斯平滑与 Sobel 梯度

读取灰度图后，转换为 `float64`，避免梯度计算中的负数或较大数值被截断。

使用 `cv2.getGaussianKernel(5, 1)` 生成一维高斯核，再通过外积 `g @ g.T` 得到二维核。手写 `filter` 函数逐位置计算图像窗口与核的对应元素乘积之和；`copyEdge` 通过复制边缘完成填充，保持输出尺寸不变。

这里的 `filter` 不翻转核，严格来说计算的是互相关。后续 Sobel 方向和 NMS 的坐标约定与这种实现保持一致。

Sobel 核为：

```text
Sobel X             Sobel Y
-1  0  1            -1 -2 -1
-2  0  2             0  0  0
-1  0  1             1  2  1
```

分别得到水平梯度 `Gx` 和垂直梯度 `Gy`。绘制梯度时使用相同的对称红蓝色标，保留梯度的正负信息。

### 3.2 Canny 边缘检测

流程为：高斯平滑 → Sobel 梯度 → 梯度幅值与方向 → 非极大值抑制 → 双阈值分类 → BFS 边缘追踪。

1. 使用 `np.hypot(Gx, Gy)` 计算梯度幅值，使用 `np.arctan2(Gy, Gx)` 计算方向，将角度转换到 `[0, 180)`。
2. 将方向近似划分为四类，沿梯度方向比较当前位置与前后两个邻点的幅值，保留局部最大值。图像坐标中行号向下增加，因此 45° 对应左上—右下，135° 对应右上—左下。
3. 在 NMS 结果上进行双阈值分类：

| 类型 | 判断条件 | 分类图显示值 |
| --- | --- | --- |
| 强边缘 | 幅值 ≥ 100 | 255 |
| 弱边缘 | 30 ≤ 幅值 < 100 | 100 |
| 非边缘 | 幅值 < 30 | 0 |

4. 将全部强边缘加入 `deque`，以八邻域进行 BFS。遇到尚未加入的弱边缘时立即标记并入队，递归式追踪所有与强边缘连通的弱边缘。孤立弱边缘被舍弃。

最终边缘使用布尔矩阵表示，绘图时 `False` 为黑色、`True` 为白色。显示值 100 和 255 仅用于分类图，不是算法中的梯度阈值。

当前 NMS 跳过最外侧一圈像素；相等幅值允许同时保留，因此并不保证所有边缘都严格只有一个像素宽。

### 3.3 Harris 角点检测

复用平滑图像的 `Gx`、`Gy`，计算 `Gx²`、`Gx·Gy` 和 `Gy²`，分别用高斯窗口进行加权汇总：

```text
A = filter(Gx², Gaussian)
B = filter(Gx·Gy, Gaussian)
C = filter(Gy², Gaussian)

M = [[A, B],
     [B, C]]

R = A*C - B² - 0.04*(A+C)²
```

每个像素对应一个局部矩阵 M 和一个响应 R。候选条件为 `R > 0.01 * max(0, R.max())`，再在二维邻域中保留局部最大响应。

实验分别改变两类窗口，组成九组对比：

| 参数 | 取值 | 作用 |
| --- | --- | --- |
| 高斯统计窗口边长 | 3、5、7 | 对梯度乘积进行加权汇总，构造 M |
| 高斯标准差 | 固定为 1 | 控制窗口内的权重分布 |
| Harris 响应系数 | 0.04 | 计算响应 R |
| 相对阈值比例 | 0.01 | 筛选正响应候选点 |
| NMS 窗口边长 | 3、9、15 | 在局部邻域内比较候选响应 |

九宫格中，每行固定高斯窗口大小，每列固定 NMS 窗口大小，红点表示保留的角点。

### 3.4 直方图均衡化

重新读取原始灰度图，独立于边缘和角点检测过程进行均衡化：

1. 逐像素统计 0～255 各灰度值出现的次数。
2. 计算累计次数 `C(v)`。
3. 找到最小非零累计次数 `C_min`，建立灰度映射：

```text
T(v) = round(255 * (C(v) - C_min) / (N - C_min))
```

其中 N 是总像素数，映射结果限制在 `[0, 255]`。通过查找表将每个像素替换成新灰度值。

如果整张图片只有一种灰度，则保留原图，避免分母为零。对比图中的两幅图像使用相同的灰度显示范围，两幅直方图也使用相同的坐标范围。

## 5. 实验观察与局限

### Canny

NMS 将较宽的梯度响应带细化。BFS 保留与强边缘连通的弱边缘，同时去除孤立弱边缘。阈值 30 和 100 针对本次图像设置，更换图像后需要重新观察结果并调整，不能将其视为通用阈值。

### Harris

Notebook 已保存的运行结果中，角点数量如下：

| 高斯窗口边长 | NMS 3 × 3 | NMS 9 × 9 | NMS 15 × 15 |
| --- | ---: | ---: | ---: |
| 3 | 103 | 78 | 68 |
| 5 | 103 | 79 | 66 |
| 7 | 102 | 79 | 66 |

固定高斯窗口时，增大 NMS 窗口会使本次实验中的角点分布更稀疏。但代码会跳过宽度为 `nms_size // 2` 的图像边界，因此数量减少同时受到边界排除范围增大的影响。

固定 NMS 窗口时，三种高斯窗口的结果接近。这里始终固定标准差为 1，新增外围位置的高斯权重较小，尤其 5 × 5 与 7 × 7 的差别有限。不能据此断言高斯统计窗口对角点检测没有影响。

当前角点 NMS 使用“等于局部最大值”的判断。如果相邻位置出现完全相同的最大响应，它们可能同时被保留，尚未对这种平台峰值进行唯一点选择。

### 直方图均衡化

均衡化后，部分暗部细节更明显，同时噪声和纹理也被增强，因此视觉效果并非一定更好。输出直方图仍包含尖峰和空隙，因为相同输入灰度的像素映射到相同输出灰度；均衡化不保证每个灰度值拥有相同数量的像素。

本实现侧重理解算法和展示中间步骤，使用显式循环，未进行大图性能优化，也未开展与 OpenCV 实现的严格数值对齐评测。
